### Improved

- Admin › Plugins now has three sections: Included, Installed and Available. Each plugin that comes with Subduction has a switch to turn it on or off, says when it hasn't been set up yet, and links to its connections in Workflows.
- Admin › Plugins now tells you what is in the way of turning a plugin off. If enabled workflows still use it, or runs are still waiting on its triggers, it names them and the plugin stays on. Runs that are waiting won't resume if the plugin is turned off.
- A plugin's page in Workflows no longer has its own switch. It still says "Turned off" when that is the case, and admins see a pointer to Admin › Plugins to turn it on or off.
