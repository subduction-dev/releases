### New

- **Start a workflow from ⌘K.** Type "start" and choose "Start a workflow" to pick a workflow, fill in the inputs it needs, and start it. The run opens once it starts. The command is available to authors and admins, and only when your organization's plan includes Workflows.
- **The assistant now asks before starting a workflow.** In Slack and in Chat, if you don't name a workflow, the assistant lists the ones you can start and asks which you mean. If a workflow needs inputs you haven't given, it asks for all of them in one message and starts once you answer. A request that already has everything starts straight away.

### Fixed

- **The "Keyboard shortcuts" row in ⌘K now opens the shortcut help.** Before, it closed ⌘K without showing anything.
