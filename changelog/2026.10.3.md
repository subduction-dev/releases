### New

- Admins now have an Admin area in the navigation. Its AI Management page holds the organization's model keys and model tiers, and your own Settings keeps only what is yours: crash reports, notifications, muted subjects and Slack.
- The organization now chooses its AI models by tier — Intensive, Moderate and Light — instead of one default model. Each tier uses a built-in model from the Preferred provider unless an admin picks a model by hand, and each tier shows which kinds of work use it.
- AI Management has a Usage page showing what the organization's model use cost over a month, a quarter, a year or any run of days up to two years. The total splits into Interactive and System work, then breaks down by kind of work, by model and by person, and Admin home shows the month so far.

### Improved

- Chat shows models by name, such as Claude Sonnet 5, instead of by id, in the picker, the divider and each answer. The workflow-authoring chat in Workflows now uses the same model picker as every other chat.
- Each saved model key shows when it was added, and chat's "add a key" notices now point to Admin → AI Management.
