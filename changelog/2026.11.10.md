### Improved

- Zendesk is now a plugin you manage under Admin › Plugins. Organizations that already used it have it installed automatically, and their Zendesk connections and workflows keep working as before. Other organizations can install it from Admin › Plugins.
- The Zendesk action that uploads a file from a case is no longer available. A workflow that still uses it will fail at that step.
