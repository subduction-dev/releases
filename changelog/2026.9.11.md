### New

- Every chat now shows which model is answering, next to the conversation. If you can send messages in a conversation, you can pick a different model for it. A thin divider shows where the model changed, so you can tell which answers came from which model.
- Settings › Model keys has a new Default model row. Admins use it to choose the model new conversations start on. The row becomes available once your organization adds its first model key, and existing conversations keep the model they started with.
- Mermaid diagrams in documents now appear as diagrams instead of code. This works when you read a document and when you edit it, where the diagram updates as you type, and also for documents shown inside Cases.

### Improved

- Settings › Model keys now says that keys are held for everyone in your organization. While no key has been added, admins see a small ring beside the section and on the way to Settings, and the section lists which features are waiting for a key. Removing a key now warns you that everyone in the organization will stop getting answers.

### Fixed

- When your organization has no model key, chat in Documents and Cases no longer shows an error with a Retry button that couldn't help. Instead, a notice at the bottom of the conversation tells admins where to add a key and tells everyone else that chat is disabled. Messages you send are kept.
