### New

- You can now attach files to an open case with **Attach file**, and people who can see the case can see and download them in its Files card.
- Work item forms and workflow rehearsals can now ask for a file as required evidence. File fields work inside groups and repeated items, accept drag and drop or paste, and are checked like other required fields.
- A published policy's Overview now has a "How this policy works" chart showing the stages its main procedure runs through. Each stage lists the AI steps, decisions and waits inside it.
- A draft or proposal can now include related workflows for an existing type of case. It can also include a new arrangement of workflows and documents, and none of it changes what is published until it is approved.

### Improved

- Private rehearsals now show the same case files, decisions and AI activity that live work shows.
- Pages load faster. What each page downloads before it can appear is about a fifth of what it was.

### Fixed

- Open chat threads and case pages now update right away when something finishes or is added in the background. For example, a chat run that fails in the background now shows as failed in the open thread.
