### New

- Admin › Plugins now keeps each installed plugin current. Every hour, Subduction checks for newer versions and applies them on its own. If a new version asks for something new, such as an outside host, a secret or a required setting, it waits for an admin. The admin fills in what it needs and approves it, and the update installs right away.
- Each installed plugin shows what it follows: a major version such as 1.x, the newest release, or one exact version. An admin can change this in place, and the plugin moves at once. The row also shows when the plugin was last checked.
- **Check for updates** checks every installed plugin immediately and tells you what happened.
- The page now says when a plugin is stopped and why (retired, or its version withdrawn) and when a plugin is deprecated. A newer major version is offered but never taken automatically.

### Improved

- When a run reaches a stopped plugin, the step now fails naming the plugin, the withdrawn version and the publisher's reason, and points you to Admin › Plugins. Before, it failed as an unregistered action.
- A withdrawn plugin version no longer runs again for your organization, even if a newer version fails to load.
- When the installed version was withdrawn and only older ones are offered, the button reads "Move to 1.1.0" rather than "Update to".
